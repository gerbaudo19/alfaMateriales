# Alfa Materiales — Demo

Sitio web responsive para **Alfa Materiales**, un comercio que combina **corralón de materiales para construcción** y **ferretería** en La Plata, Buenos Aires.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Despliegue

El proyecto se despliega automáticamente a GitHub Pages mediante GitHub Actions en cada push a `main`.

Sitio en vivo: https://orsoft-ar.github.io/alfa-materiales/

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
